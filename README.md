# Natural Computing: Interactive Course

An interactive web course on nature-inspired optimisation, with live 2D and 3D simulations you can play with in the browser.

## Topics

1. Why nature-inspired computing: hard problems, metaheuristics, swarm intelligence
2. Optimisation, search spaces and benchmark landscapes
3. Dispersive Flies Optimisation (DFO)
4. DFO in practice
5. Genetic Algorithms and the Travelling Salesman Problem
6. Stochastic Diffusion Search (SDS)
7. Ant Colony Optimisation (ACO)
8. Particle Swarm Optimisation, Differential Evolution and fair comparison

Plus an algorithm arena for head-to-head experiments and a formula toolkit where every symbol is labelled.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Built with React, Vite and three.js.
